# BiTaYaDe
文档内容对比工具。能够读取两个 Word 文档（.docx）或者TXT文档或者直接粘贴文本内容，然后利用差异对比算法，直观地展示出两个版本文档之间的内容差异。
# 📄 文档对比工具

一个轻量级、注重隐私的在线工具，用于在浏览器中直接比较两个 Word 文档（.docx）的内容差异。

## ✨ 功能特性

*   **隐私安全**: 所有文件处理和对比过程均在您的本地浏览器中完成，文档内容不会上传到任何服务器，确保数据安全。
*   **直观对比**: 能够清晰地高亮显示两个版本文档之间的差异，包括新增、删除和修改的内容。
*   **无需安装**: 这是一个纯前端网页应用，无需安装任何软件，打开即用。

## 🚀 如何使用

1.  在浏览器中打开 `index.html` 文件。
2.  分别上传您想要对比的两个 `.docx` 文档（例如：原版文档和修订版文档）。
3.  工具会自动解析并对比两个文件的内容。
4.  在页面上查看对比结果，通常会以高亮或特殊标记的形式展示差异。

## ⚙️ 技术栈

*   **核心解析库**: <Mammoth.js> - 一个用于将 .docx 文件转换为 HTML 的 JavaScript 库。
*   **差异对比库**: <diff> - 一个用于比较文本或数据序列的 JavaScript 库。

## 📂 文件说明

| 文件名 | 描述 |
| :--- | :--- |
| `index.html` | 应用的主入口文件，包含用户界面和基本逻辑。 |
| `mammoth.browser.min.js` | Mammoth.js 库的浏览器端压缩版本，负责核心的 .docx 解析工作。 |
| `diff.min.js` | 一个用于文本内容差异对比的 JavaScript 库。 |
